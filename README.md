# Tayssir Guebouri Portfolio

A responsive, static portfolio website built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish for free
You can deploy the folder using Netlify Drop or connect it to a GitHub repository and deploy through Netlify. Keep `index.html`, `styles.css`, `script.js`, and the `assets` folder together.

## Included
- Dark navy / blue visual design
- Responsive layout for desktop and mobile
- English / Arabic language switch
- Mobile navigation menu
- Project cards for Hydraulic Emergency Engineer and Sponge City
- Sponge City screenshots supplied by Tayssir
- Live game link: https://tayssirgbr.github.io/Emergency-Engineer/
- LinkedIn contact link

## Update later
Edit project descriptions and links in `index.html`. Replace or add images in `assets/` and update their paths in the same file. No build tools or framework are required.
